# Wine Quality Prediction

**Domain**: Regression Analysis

## Overview

Predicts red wine quality based on physicochemical properties using Linear Regression and Random Forest Regressor. Includes comprehensive EDA, feature scaling, model comparison, and feature importance analysis.

## Dataset

UCI Wine Quality dataset (red wine variant) -- 1,599 samples, 12 features.

## Methodology

1. Exploratory Data Analysis (distribution analysis, correlation heatmaps)
2. Feature scaling (StandardScaler)
3. Linear Regression baseline
4. Random Forest Regressor with feature importance
5. Model comparison

## Key Files

- `ML_Project.ipynb` -- Full notebook
- `winequality-red.csv` -- Wine dataset
