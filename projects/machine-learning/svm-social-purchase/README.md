# SVM Social Purchase Classification

**Domain**: Support Vector Machines

## Overview

Classification model using Support Vector Machines (SVM) to predict social network purchase behavior. Includes data preprocessing, grid search hyperparameter tuning, and decision region visualization.

## Methodology

1. Data preprocessing and feature scaling
2. SVM with RBF kernel
3. Grid search cross-validation (C, gamma parameters)
4. Decision boundary visualization

- `Social Purchase SVMs Assignment 3.ipynb` -- Full notebook
- `social data.csv` -- Social network dataset
