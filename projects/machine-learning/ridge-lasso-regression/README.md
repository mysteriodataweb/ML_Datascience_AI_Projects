# Ridge & Lasso Regression for Salary Prediction

**Domain**: Regularized Regression

## Overview

Practice exam implementing Linear Regression with Ridge and Lasso regularization to predict baseball player salaries. Demonstrates the effect of L1 and L2 regularization on feature selection and model performance.

## Dataset

Hitters dataset (from ISLR package) -- baseball player statistics.

## Methodology

1. Data preprocessing and feature encoding
2. Linear Regression baseline
3. Ridge Regression (RidgeCV with cross-validation)
4. Lasso Regression (LassoCV with cross-validation)
5. Coefficient analysis and feature selection

## Key Files

- `Practice-Exam-Machine-Learning-wih-Ridge-and-Lasso.ipynb` -- Full notebook
- `Hitters-fs.csv` -- Baseball player dataset
